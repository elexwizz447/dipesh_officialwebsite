Active Demand modelling Data-centre power

AI data-centre power systems: from inference request to facility load

An end-to-end model that turns AI inference demand into a real power curve — linking request rates, compute workload, batching behaviour and facility load in one framework instead of the static per-query estimates most published figures rely on.

  • Replaced static per-query energy assumptions with regional diurnal demand curves and task-level FLOP intensities.
  • Modelled dynamic batching, model FLOPs utilisation (MFU) and utilisation-driven facility overhead.
  • Integrated every stage into a single request-to-power analytical pipeline.

Phase 1 — global aggregate demand Complete

  • 24-hour canonical inference curve built from a baseline plus Gaussian peaks.
  • Regional weights and time-zone shifts composed into a global demand profile.

Phase 2 — hardware utilisation to dynamic power In progress

  • Mapping regional request rates to per-task FLOPs, batch formation and MFU-driven GPU requirements.
  • Deriving hardware utilisation and the resulting dynamic GPU cluster power.

Unified ANFIS control for AVR and load-frequency control

A MATLAB/Simulink framework comparing an adaptive neuro-fuzzy controller against tuned PID for simultaneous voltage and frequency regulation in interconnected power systems.

How it was built

  • Unified AVR–LFC system dynamics including synchronous generator swing equations and exciter loops.
  • Two scenarios: a baseline tuned PID and a unified ANFIS controller trained by hybrid learning.
  • Voltage and frequency response observed under load fluctuation and variable inertia.

What came out of it

Cross-coupling is real and measurable

Frequency deviation visibly moves terminal voltage and the reverse, which a split controller design ignores.

ANFIS wins in low inertia

Faster settling, lower overshoot and smoother damping than PID, without manual retuning per operating point.

One controller is enough

A single ANFIS controller regulated both AVR and LFC loops simultaneously.

Grid-forming inverters in PV–hydro microgrids

How grid-forming inverters with virtual synchronous machine control can hold up a low-inertia system that mixes solar PV with hydro generation.

Simulation approach

  • Dynamic PV–hydro microgrid model including the swing equation for virtual inertia interaction.
  • Grid-forming inverter establishes voltage and frequency; the hydro unit synchronises to it.
  • System response tested against PV fluctuation, load steps and hydro output variation.

Findings so far

Shallower frequency dips

The GFM–VSM inverter supplies fast support during sudden load or PV changes.

Smoother hydro coordination

The hydro generator synchronises with noticeably fewer oscillations.

Standards-compliant ride-through

PV inverter behaviour follows IEEE 2800 ride-through requirements through voltage and frequency disturbances.

AI-integrated home automation system

A working automation stack that learns from how a household actually behaves: an ESP32 publishes sensor telemetry over MQTT, a server-side logistic regression model decides, hysteresis stops it oscillating, and a physical switch always overrides the model — every override is logged and fed back into retraining.

Hardware prototype

  • ESP32 reads sensors and publishes telemetry over MQTT.
  • Initial training set logged with Arduino and PLX-DAQ.

Control architecture

  • Telemetry → inference → hysteresis decision → relay actuation.
  • Voice control through Google Home and Alexa; local manual override takes priority.
